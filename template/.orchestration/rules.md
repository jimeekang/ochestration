# 공통 규칙
- Claude와 Codex는 같은 프로젝트 폴더·worktree에서 일한다. 새 worktree·브랜치를 만들지 않는다.
- 파일 소유권: 브리프의 범위만 수정한다. 같은 파일을 동시에 두 작업에 주지 않는다.
- 범위 밖 문제는 고치지 말고 보고한다.
- 지정 모델·effort를 임의로 바꾸지 않는다. 재개할 때도 같다.
- 검증은 브리프의 완료 조건대로 실행하고, 미실행은 그대로 밝힌다.
- Codex 결과 파일은 .orchestration/runs/에 두고 커밋하지 않는다.
- 커밋·푸시·배포는 사용자 승인 범위에서만 한다.
