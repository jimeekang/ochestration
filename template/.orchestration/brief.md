# 작업 브리프 형식 (팀장→Codex)
역할: analyst|implementer|quick_edit|explorer|reviewer
목표: 한 문장
배경: 관련 설계·결정·파일 경로
범위: 수정 가능한 파일·디렉터리
금지: 건드리지 않을 파일·동작(읽기 명령은 막지 않는다)
완료 조건: 실행할 검증 명령과 기대 결과
보고: .orchestration/report.md 형식
브리프 하나에 역할 하나. 같은 파일을 두 브리프에 넣지 않는다. 셸 인자로 넘기므로 작은따옴표(')는 쓰지 않는다. dispatcher에게는 브리프만 넘긴다.
