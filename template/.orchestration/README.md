# 오케스트레이션 문서 색인
모든 md 파일은 350자 이하로 유지한다. 길어지면 파일을 나눈다.
- flow.md: 작업 흐름 5단계
- roles.md: 역할별 모델·effort·sandbox
- roles/: 역할별 상세 지침(Codex가 읽음)
- brief.md: 팀장→Codex 작업 브리프 형식
- report.md: Codex→팀장 결과 보고 형식
- codex-call.md, codex-resume.md: Codex 호출·재개 방법
- rules.md: 공통 규칙
- runs/: Codex 결과 파일(커밋하지 않음)
