# Claude × Codex 오케스트레이션
Claude 팀장이 Codex에 구현을 맡기는 설정. 프로젝트마다 설치:
```
git clone https://github.com/jimeekang/ochestration ~/orch
~/orch/install.sh .          # Windows: ~/orch/install.ps1 -Target .
```
Claude·Codex 채팅에 붙여넣기: "github.com/jimeekang/ochestration을 ~/orch에 클론하고 install을 이 프로젝트에 실행해줘"
뒤에 Codex 신뢰 허용, Claude 재시작. 갱신은 -Force.
