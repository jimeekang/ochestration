# Claude × Codex 오케스트레이션
프로젝트 폴더에서 실행.
**Windows (PowerShell)**
```
git clone https://github.com/jimeekang/ochestration $HOME\orch
& $HOME\orch\install.ps1 -Target .
```
**Mac (터미널)**
```
git clone https://github.com/jimeekang/ochestration ~/orch
bash ~/orch/install.sh .
```
설치 후 Codex 신뢰 허용, Claude 재시작. 갱신은 -Force(Mac은 --force).
